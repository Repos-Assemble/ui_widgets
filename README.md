# ui_widgets

A small collection of reusable Flutter widgets that fill gaps in the standard Material widget set.

## What's inside

- **Copyable text** — text that users can tap to copy
- **Expansion panel** — a customized expandable/collapsible panel
- **Gaps** — simple spacing widgets for layout (instead of raw `SizedBox` everywhere)
- **Ink well** — a customized tap-ripple wrapper
- **List view** — a customized list view helper

## Installation

```yaml
dependencies:
  ui_widgets:
    git:
      url: https://github.com/Repos-Assemble/ui_widgets.git
      ref: main
```

## Usage

```dart
import 'package:ui_widgets/ui_widgets.dart';
```
